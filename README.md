# Rcomandor

Мод свободной камеры (Freecam) для Minecraft **1.21.11**, Fabric.

## Управление (меняется в Настройки → Управление → Rcomandor)

| Клавиша | Действие |
|---|---|
| **F4** | Включить / выключить свободную камеру |
| **W A S D** | Полёт камеры |
| **Пробел / Shift** | Вверх / вниз |
| **Ctrl (бег)** | Ускорение ×2.5 |
| **] / [** | Скорость камеры + / − |
| **N** | Проход сквозь блоки вкл/выкл (по умолчанию включён) |

Пока камера отделена, игрок стоит на месте, а клики мышью (ломать, ставить, бить) отключены.

## Как собрать .jar без установки Java (через GitHub)

1. Создай новый репозиторий на github.com (можно приватный).
2. Нажми **Add file → Upload files** и перетащи всё содержимое этой папки (включая папки `.github`, `gradle`, `src`).
   Папку `.github` браузер иногда не загружает — тогда создай файл вручную: **Add file → Create new file**, путь `.github/workflows/build.yml`, вставь содержимое.
3. Открой вкладку **Actions** — сборка запустится сама (или нажми **build → Run workflow**).
4. Когда появится зелёная галочка, открой запуск и скачай архив **Rcomandor** внизу страницы.
5. Внутри будет `rcomandor-1.0.0.jar`. Положи его в папку `mods` вместе с **Fabric API** для 1.21.11.
